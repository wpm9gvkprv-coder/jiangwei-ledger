# 第一阶段 页面与接口规划
庞润泽（241310122），组长，负责Vue前端和可视化。

|页面|功能|对应后端|
|---|---|---|
|登录与注册|注册、登录、登录失效提示|auth/register、auth/login|
|总览|收支卡片、趋势、预算、近期账单|statistics、budgets、bills|
|账单明细|增删改查、分页筛选、智能分类、异常分析|bills、categories、intelligence|
|消费分析|分类饼图、收支柱状图、结余折线图|statistics/summary、categories、trends|
|月度预算|设置预算、进度、预警|budgets/{month}|
|分类管理|默认与自定义分类|categories|
|异常提醒|列表、分析详情、标记已读|alerts、intelligence/bills/{id}/anomaly|
|个人信息|查看与编辑名称、退出|me、auth/logout|

响应按code/message/data解包；JWT存于sessionStorage；请求携带Bearer令牌；401清理会话并跳转登录；生产部署使用/api同源反向代理。
金额仅显示后端统计结果，图表与账单使用同一月份与收支口径；默认分类ID从接口读取。
桌面端固定侧栏，窄屏改为可关闭抽屉导航；图表由ResizeObserver调整尺寸。
