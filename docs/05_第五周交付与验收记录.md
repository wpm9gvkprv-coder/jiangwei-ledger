## 2. 验收演练（本周实测）

按《系统使用说明书》第二章在干净环境复跑，记录如下：

| 步骤 | 命令 / 操作 | 实测结果 |
| --- | --- | --- |
| 1 建库导脚本 | `01_schema.sql` → `02_defaults.sql`（可选 `03_demo_data.sql`） | 5 张表、7 条默认分类正常，客户端需 utf8mb4 |
| 2 起后端 | `java -jar release/ledger-backend-1.0.0.jar` | `GET /api/health` 返回 `{"code":0,"data":{"status":"UP"}}` |
| 3 起前端 | `API_TARGET=http://127.0.0.1:8080 npm run dev` | 5173 可访问，`/api/health` 经代理透传正常 |
| 4 登录 | 注册新账号或演示账号 | 登录成功写入令牌，未登录访问业务接口返回 401 |
| 5 五步演示 | 登录 → 记账（看推荐）→ 统计（三图一致）→ 预算（两档预警）→ 提醒（样本与上界） | 全流程走通，数值与文档一致 |

补充了两个一键启动脚本 `启动后端.bat`、`启动前端.bat`，脚本内先检查端口占用，避免重复启动报
“端口被占用”，并在启动后自动打开浏览器。
